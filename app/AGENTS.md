# 项目定位

- 这是一个小程序项目，所有修改都要在此基础之上进行。
- `D:\project\宠物APP\app` 是后续唯一需要继续开发和维护的项目；原项目 `D:\project\pet` 仅作为历史参考，不再修改。

# 页面修改范围规则

- 默认一次任务只修改用户当前明确指定的一个页面。
- 未经用户明确允许，不得修改、重构、删除或顺带调整其他页面的内容、样式、结构、交互与文案。
- 即使其他页面存在相似问题、可复用修改或一致性需求，也只能向用户说明，不得自行修改。
- 如果完成当前页面的修改必然会影响其他页面，必须先说明影响范围并获得用户明确许可后再执行。
- 公共组件、全局样式、共享配置等可能影响多个页面的文件，也视为“其他页面范围”；修改前必须确认不会影响其他页面，否则先征得用户许可。

# 开发阶段运行规则

- 当前项目处于开发阶段，用户会自行运行项目并查看修改效果。
- 默认只进行源码修改与必要的静态检查，不主动执行编译、构建、打包或生成发布产物。
- 只有用户明确提出需要编译、构建、打包或发布时，才执行相应操作。
