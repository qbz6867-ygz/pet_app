# 宠物百科管理后台开发规范

本文件适用于 `admin/` 管理后台，并继承项目根目录 `AGENTS.md` 的全部规则。

## 后台字号规范

管理后台统一使用 `px` 和 `admin/src/styles.css` 中定义的字号变量。后续新增或调整文字样式时，不得随意添加新的固定字号，应优先使用以下变量：

| CSS 变量 | 字号 | 建议用途 |
| --- | --- | --- |
| `--font-caption` | `11px` | 图表刻度、徽标、极小辅助信息 |
| `--font-meta` | `12px` | 日期、数量说明、状态标签 |
| `--font-body-sm` | `13px` | 表格正文、筛选项、次要按钮 |
| `--font-body` | `14px` | 默认正文、输入框、导航菜单、主要按钮 |
| `--font-card-title` | `15px` | 卡片标题、表格重点文字 |
| `--font-section-title` | `17px` | 页面模块标题 |
| `--font-page-title` | `26px` | 页面主标题 |
| `--font-stat` | `29px` | 统计数值、核心数据 |

### 使用要求

1. 普通文字的最小字号为 `11px`，不得重新使用 `7px`、`8px`、`9px`、`10px` 等过小字号。
2. 新增样式必须通过 `var(--font-*)` 引用上述字号变量，不直接写同值的固定 `px`。
3. 同类组件必须使用同一字号层级，例如所有表格正文统一使用 `--font-body-sm`，所有页面主标题统一使用 `--font-page-title`。
4. 图标尺寸由 `AdminIcon` 的尺寸属性或图标样式控制，不得通过文字字号变量控制。
5. 用户头像文字、特殊评分数字等确需使用规范外字号时，应先说明原因，并保证同类界面一致。
6. 调整字号后应检查表格、筛选栏、统计卡片和弹出菜单，避免文字换行、遮挡或溢出。
